# Pose regression fixtures

The 12 JSON files contain 48 **synthetic_regression** scenarios (normal input, two form deviations, tracking lost) with timestamped landmark sequences. They are deterministic software regression data, NOT real video-derived accuracy validation or expert ground truth. Temporal cycle tests separately cover the 11 repetition motions and interrupted tracking; existing plank duration/rate tests remain.

Actual dataset: EXTERNAL SETUP REQUIRED. Collect consented, de-identified MediaPipe landmark sequences; do not commit raw videos, names or health identifiers. Independently label exercise, repetitions/hold time, visible/occluded frames and errors with qualified reviewers. Cover different body proportions, camera orientations, lighting and Android/iOS devices. Keep a held-out participant split. Use `node scripts/evaluate-pose.mjs dataset.json report.json`; format is `sessions[{exercise,participant_id,device,lighting,view,expected_reps|expected_seconds,frames[{time_ms,landmarks,expected_visible}]}]`, optional `reviewer` and `real_data_attested`. Attestation is provided by the data owner, not independently authenticated by the script. It measures count/hold errors and tracking coverage, not clinical correctness. Supply `aspect_ratio` as frame height/width for actual recording dimensions.
