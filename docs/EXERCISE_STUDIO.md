# 운동 시범 74종

라이브러리의 맨몸운동 42종과 기구 운동 32종 모두 전용 3D 관절 동작을 사용합니다. 예전 SVG 좌표를 입체로 옮기던 경로는 기존·알 수 없는 운동의 보조 안내에만 남습니다. 스쿼트·런지 등 카메라 자세 코칭은 기존 맨몸운동 7종을 지원하며, 기구 운동 32종은 동작 시범입니다.

`bodyweightRig.js`, `standingCatalogRig.js`, `floorCatalogRig.js`, `equipmentCatalogRig.js`는 관절 길이와 실제 지지점을 유지합니다. 좌우 교대, 발 이동·착지, 팔꿈치 굽힘, 몸통 회전, 옆으로 눕는 자세와 캣카우의 등 곡선을 각각 작성했습니다. 의자·벽·벤치·머신·케이블·페달·발판은 동일한 월드 좌표의 접촉 메타데이터를 사용합니다. 운동별 고정 구도는 전체 동작과 기구 부품의 경계를 포함하여 계산합니다.

기존 CC0 인체 표면에 운동용 의상 색상, 직물 노멀 맵, 피부와 머리카락의 서로 다른 재질, 로컬 스튜디오 반사를 적용합니다. 외부 이미지·HDR·모델 서버를 요청하지 않습니다. 시범은 지지점이 일정한 표준 체형을 사용하며, 개인 체성분 마네킹은 별도 화면에서 측정값을 계속 반영합니다. 한 번에 선택한 운동 하나만 WebGL로 표시하고, 목록은 번들에 포함된 실제 3D 렌더 이미지 74장을 사용합니다.

화면에서 정면·45°·측면·후면·자유 회전, 재생·정지, 0.5×·0.75×·1× 속도, 좌우 반전, 단계 선택과 구간 이동을 제공합니다. 화면 밖으로 나가거나 앱이 숨겨지면 재생을 중지합니다. 2D 보조 안내는 재생 설정에서 선택할 수 있습니다.

검증은 관절 길이, 반복 경계의 연속성, 실제 피부·신발·좌석 접촉, 기구 앵커, 손 회전, 전체 구도의 투영 검사와 실제 모바일 브라우저 WebGL 렌더링으로 구성됩니다. `e2e-local/all-exercise-renders.spec.js`는 74종 각각의 세 구간을 캡처하고 실제 인체 메시가 렌더되었는지 확인합니다. 목록 이미지 재생성은 로컬 개인용 개발 서버를 시작한 뒤 `node scripts/render-exercise-thumbnails.mjs`로 실행합니다. 생성한 이미지의 단계·방향·SHA-256은 `public/exercise-thumbnails/manifest.json`에 기록합니다.

작성된 자세 이해용 애니메이션입니다. 전문가 모션 캡처나 운동별 임상 검증을 완료한 자료가 아니며, 실제 Android 기기의 카메라 정확도·프레임 속도는 별도 실기기 확인이 필요합니다. 카메라 모델 체크섬, 기기 내 암호화 저장소, 체성분 마네킹과 수정판의 앱 ID·서명을 유지합니다.
