# Synex Coach / Synex Member — 2026-11-06

최신 IR의 헬스장 B2B, 회원의 운동 실행·3D 이해, 건강생활실천지원금 흐름에 맞춘 설치 가능한 기기 저장 버전입니다.

## 구현 범위
- Coach: 회원 등록·검색, 운동명 부분 검색, 주 2–5회 계획, 기본/짧은 하루 루틴, PT 날짜 우선 배치, 60분 일정 중복 방지, 일정 변경 시 계획 재생성, 운동·식단 기록 조회, 식단 사진 피드백.
- Member: 오늘 홈, 트레이너 루틴 선택·완료/부담 기록, PT 일정, 식단 촬영·사진 기록, 피드백 확인, 기존 3D 인체·캐릭터·운동 시범 보존.
- OCR: Tesseract 한글·영어 모델을 번들에 포함. 기기에서 사진 처리 → 항목명 기준 수치 추출 → 사용자 확인 → 기존 체성분 저장 API → 3D 화면. 인식하지 못한 값은 빈칸 유지. 임의 수치를 생성하지 않습니다.
- 정책: 예방형/관리형 안내, 최대 적립·신청·실천·사용 절차, 실천 준비 저장, 기존 운동 알림 설정 연결.

## 연결 상태
- Android 두 앱은 별도 패키지입니다: `com.synex.health.coach`, `com.synex.health.member`.
- 데이터는 기존 AES-GCM 기기 저장소의 별도 gym 문서에 저장합니다. 기존 체성분 기록의 문서와 분리합니다.
- 이 설치본에는 운영 서버, 인증업체 계약, 공단 연동 권한이 구성되어 있지 않습니다. 간편인증 진입 화면은 이를 표시하고 개인정보를 전송하거나 인증 성공을 생성하지 않습니다.
- 다른 기기 사이의 공유는 사용자가 확인·동의한 JSON 파일로 동작합니다. 실시간 동기화 또는 인증된 계정 간 원격 전송으로 표시하지 않습니다. 공유 파일에는 개인 기록과 사진이 포함되므로 실제 수신자를 확인합니다.
- 회원은 최초 계획 파일로 연결되고 이후 다른 회원/다른 코치의 파일은 차단합니다. 트레이너도 소속 회원 ID와 코치 ID가 일치하는 기록만 가져옵니다. 이는 로컬 파일의 일관성 검사이며 서버 계정 인증을 대체하지 않습니다.
- 스토어 출시용 서명이 아닌 Android debug 설치본입니다. 기존 개인용 앱과 별도 설치됩니다.

## 실행 / 빌드
```sh
cd frontend
npm ci
VITE_LOCAL_ONLY=true VITE_APP_AUDIENCE=member npm run dev
# /health = 회원, /coach = 트레이너 (개발 브라우저에서 확인)
VITE_LOCAL_ONLY=true npx vitest run tests/gym-workflow.test.js tests/LocalApi.test.js tests/Offline.test.js tests/DeviceBoundary.test.jsx
node scripts/build-gym-apps.mjs
```
빌드 스크립트의 SDK/JDK/캐시 기본 경로는 현재 작업 환경에 맞췄습니다. 다른 환경에서는 ANDROID_HOME, JAVA_HOME, GRADLE_USER_HOME, SYNEX_GYM_OUTPUT을 지정하세요. 사내 프록시를 사용하지 않는 환경에서는 스크립트의 Gradle proxy 옵션을 실제 환경에 맞춰 조정하세요.

## 2.1.0 품질 개선 (2026-11-06)
- 사용자 요청에 따라 서버 배포·인증업체·공단 연동은 보류했습니다. 공유 파일 방식은 그대로입니다.
- Coach: 오늘 PT·피드백 대기·회원별 주간 실천 현황, 회원 상세·목표·기기 내 메모, 검색, 회원별 화면 바로가기.
- 루틴 스튜디오: 기존 계획 불러오기, 세트·횟수·시간·휴식·순서 편집, 기본/가벼운 루틴, 예상 시간, 명시적 시작 주, 화면 이동 시 확인 후 암호화 임시 저장.
- PT 주간 캘린더, 변경·취소 확인, 60분 중복 방지, 일정 재배치 시 사용자 지정 운동 강도 유지.
- Member: 오늘 할 운동, 주간 완료일, 실제 체성분 값과 3D 연결, 루틴 선택, 세트 체크·휴식 카운트다운·재시작 후 복구, 운동 중 실제 3D 시범, 수행량과 부분 완료 기록.
- 식단: 앨범·촬영 선택, 피드백 대기/완료 필터, 회원 기록과 트레이너 답변 왕복 공유.
- 주간 완료일은 동일 날짜 중복 기록을 1일로 계산하고 부분 완료일은 완료일에 포함하지 않습니다.

## 2.2.0 사용성·오류 수정 (2026-11-06)
- 휴대폰 전체 메뉴: 지원금·사진 인식·3D 시범·비교·알림·개인정보로 바로 이동. 접근 가능한 dialog, Esc 닫기, 화면 이동 시 스크롤 초기화.
- 루틴 저장 툴바 고정, 세트 편집 바로가기, 저장 후 공유 바로가기, 터치 영역 확대. 선택 회원을 다른 관리 화면에서도 유지.
- 운동 일시정지·이어하기, 일시정지 시간 제외, 휴식 잔여 시간 유지. 화면을 벗어나거나 숨기면 일시정지. 수행 세트가 0개여도 확인 후 기록 없이 취소 가능.
- 사진 교체 시 이전 수치/확인 상태 초기화. 이미지 처리 중 입력 잠금. 측정일 변경 후 재확인 및 저장 가능.
- 공유 파일에서 빈 운동·객체 형태 수치·잘못된 날짜·시간을 사전 차단. 최근 기록 중심으로 11MB 이내 사진을 포함하고 포함 건수를 표시; 원래 기록은 삭제하지 않음.
- 지난 시간의 PT·존재하지 않는 날짜·역순 횟수 범위를 차단. 피드백 이동 시 암호화 임시 저장, 확정 저장 시 초안 제거. 회원 등록 연속 클릭 방지.
- React 화면 오류 시 재시도/홈 복구 화면. Android WebView 렌더러 종료 시 앱 강제 종료를 대신하는 네이티브 복구 화면과 명시적 다시 열기. 자동 재시도 루프나 저장 데이터 초기화 없음.
- 서버·간편인증·공단 연결 보류는 유지합니다.

패키지: 기존과 동일 / versionCode 2026110603 / versionName 2.2.0-gym.
