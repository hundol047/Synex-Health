# 2026-10-25 모의 검증 및 Android 테스트판

실제 사람 영상, 실제 휴대전화 또는 외부 평가 자료를 사용하지 않았습니다. 아래 결과는 소프트웨어 회귀 테스트이며 운동 정확도 비율, 실기기 합격, 임상 검증을 의미하지 않습니다. 운영용 실제 영상 증거 게이트는 유지합니다.

74개 카탈로그 운동마다 정지 관절에 미세한 잡음을 넣은 시퀀스, 추적 끊김, 화면 이탈, 누락된 관절, 낮은 관절 신뢰도를 자동 입력했습니다. 별도로 팔꿈치 각도를 조절한 합성 시퀀스로 전체 반복·부분 반복·반복 도중 추적 손실을 검사했습니다. 같은 스쿼트 기반 관절의 강건성 검사를 각 운동의 정자세 검증으로 해석하면 안 됩니다. 기존 12개 운동별 합성 시퀀스와 카메라 권한·모델 실패·중지 회귀 검사도 함께 실행합니다.

발견 및 수정:
- 분석에 사용하지 않는 얼굴 관절이 null인 프레임이 관절 좌표 변환을 중단할 수 있었습니다. 선택 관절 누락을 안전하게 처리하고 33개 구조를 검사합니다.
- 추가 카탈로그 분석기가 시작 각도에서 일정 범위만 움직여도 부분 동작을 1회로 셀 수 있었습니다. 프로필의 양쪽 끝 각도 통과와 복귀를 확인한 후에만 횟수를 올립니다. 추적 손실은 진행 중 반복을 무효화합니다. 임계값 자체의 사람 대상 타당성은 검증되지 않았습니다.
- 서버 주소 없는 비운영 APK에서 시험할 수 있도록 별도 로컬 카메라 테스트 화면을 제공합니다. 명시적 동의 후 74개 운동 선택·시범·관절 추정·선택형 음성을 시험합니다. 영상 저장/업로드와 계정 건강기록 기능을 제공하지 않으며 종료·철회 시 카메라를 해제합니다. 운영 빌드는 이 경로로 서버 권한 검사를 우회하지 못합니다.

설치: Android 테스트 APK를 설치하고 온보딩 이후 ‘서버 없이 운동 카메라 테스트’를 선택합니다. 실제 기록·학교 연동은 운영 서버 연결이 별도로 필요합니다. 테스트 APK는 스토어 출시판이 아닙니다. 기존 앱과 서명이 다르면 업데이트 설치가 실패할 수 있으므로 기존 건강기록 백업 없이 기존 앱을 삭제하지 마세요.

실제 모델을 사용한 가상 카메라 검사에서 .task 파일의 Content-Type이 생략되면 존재하는 모델까지 거절하는 문제를 추가로 수정했습니다. HTML 응답 거절은 유지하고 바이너리 파싱은 모델 로더에서 수행합니다. 모의 Android 화면에서 서버 API를 모두 차단한 상태로 74개 선택 목록, 번들 모델 구동, 사람이 없는 합성 영상 판정 보류, 동의 철회 시 카메라 트랙 종료를 확인했습니다. 3D 시범에는 API 대신 명시적인 예시 체형을 전달합니다.
