# 학교별 사용과 연동 준비

학교 목록은 제휴기관 목록이 아니다. 초기 20개 학교/캠퍼스 선택, 이름·지역 검색, 미등록 학교 요청 저장, 관리자 학교 등록을 제공한다. 모든 학교의 공식 연결 상태는 `not_connected`이다. 요청 저장을 연결 완료로 표시하지 않는다.

- 학생: `GET /api/schools`, `PUT /api/health/school` (school_id, share_with_center), `POST /api/schools/request` (name).
- 관리자: `GET /api/admin/school-requests`, `POST /api/admin/schools` (id,name,region), `PUT /api/admin/counselors/{counselor_id}/school` (school_id).
- 상담사 학교는 관리자가 지정. 학생이 프로필 수정으로 학교·공유·역할 필드를 우회할 수 없다.
- 상담사는 동일 학교 + 공유 동의 학생만 목록·상세·측정·루틴 조회와 메모 작성 가능. 상담 메모도 소속 학교 기준으로 분리. 관리자 권한은 기관 운영 목적으로 별도 관리한다.
- 학교 변경 UI는 공유 체크를 해제하고 다시 동의받는다. 공유 범위는 누적 체성분·운동·AI분석 기록이며, 해제 후 조회는 즉시 차단된다. 이미 확인·내보낸 자료를 회수하는 기능은 아니다.
- OIDC 사용자 최초 프로필 조회 시 본인 계정을 생성한다. 학교 선택은 본인 신고 소속이며 재학 인증을 의미하지 않는다. 공식 인증 배포 전에는 학교 명부/SSO 확인 절차를 추가해야 한다.

## 실제 학교 연동에 필요한 작업

학교 건강센터의 승인된 API/파일 사양·학생 매칭 식별자·접근권한·동의 절차가 필요하다. InBody/Biogram 어댑터는 아직 외부 호출을 구현하지 않았다. 현재 사용 가능한 경로는 사용자 수동 입력/CSV이며 인증키를 브라우저에 저장하지 않는다. 실제 학교별 SSO issuer/audience/학교 매핑 검증과 데이터 수신 통합 테스트 후에만 연결 상태를 변경해야 한다.

개발용 역할 전환은 `AUTH_MODE=demo` 전용이다. 실제 데이터를 넣기 전 OIDC와 학교 계정 매핑을 검증해야 한다. 인증 설정 오타는 데모로 강등하지 않고 요청을 거절한다. OIDC 모드에서 예시 계정·측정값을 자동 생성하지 않는다.
