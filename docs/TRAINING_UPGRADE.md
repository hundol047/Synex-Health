# 운동 기록·루틴 사용성 보완

## 구현

- 일반 운동 기록과 운동 따라하기에서 세트마다 외부 중량(kg), 반복 횟수, 준비/본 세트를 기록합니다. 중량 빈칸은 null로 저장하며 체중을 추정해서 더하지 않습니다. 덤벨은 한 손의 표시 중량 기준이며 양측 환산을 하지 않습니다.
- 서버는 세트 목록의 숫자 범위·운동 유형을 검증하고 세트 수와 반복 요약을 계산합니다. 목록 없는 기존 기록도 읽습니다. 카탈로그 ID를 서버에서 확정해 루틴이 달라져도 같은 운동의 과거 기록을 확인할 수 있습니다.
- 새 목록도 기존 AES-GCM 오프라인 보관·재전송·revision 충돌 해결을 사용합니다. 충돌 화면에 양쪽 중량·횟수를 표시합니다. 서버를 먼저 업데이트한 뒤 새 앱을 배포해야 합니다. 구형 서버는 새 필드를 무시할 수 있습니다.
- 루틴 카드에서 운동 한 개를 교체합니다. 성인 문진·통증 차단·현재 프로필·장비·장소를 서버에서 다시 검사합니다. 같은 움직임 유형 및 같은 시간/횟수 유형의 쉬운 운동만 후보로 제공합니다. 새로운 루틴으로 저장하고 과거 루틴·과거/미전송 기록은 그대로 유지합니다. 동시 교체는 최신 루틴 확인과 계정별 DB 잠금으로 충돌을 거절합니다.
- 최근 8주 완료 일수·수행 세트·기록된 외부 중량×횟수를 표시하고, 운동별 기록을 비교합니다. 준비 세트는 제외하고 중단 전 수행한 세트는 포함합니다. 기간은 기기 현지 월요일 기준입니다. 구형 기록의 세트는 준비 세트 구분이 없어 기존 완료 세트 수를 표시합니다.
- 라이브러리에 카메라 참고 지원 운동 필터, 모든 카드에 지원/미지원 표시를 넣었습니다. 개념 애니메이션과 준비·수행 체크 안내를 구분합니다.
- 기기 건강 기록은 별도 화면 내 동의를 켠 경우에만 일별 활동 표로 요약합니다. 서버 전송·영구 보관 없이 화면을 나가면 사라집니다. 최대 100건 조회 제한 때문에 하루 전체 합계라고 표시하지 않습니다. 중복 ID·겹치는 시간 구간·자정을 넘는 표본은 제외하며 앱의 운동 완료율과 합산하지 않습니다. 겹침 제거는 완전한 플랫폼 원본 집계가 아닙니다.

## 범위와 남은 검증

- 자동 증량 처방, 장기 정체 진단, 실측 근력 추정은 추가하지 않았습니다. 서로 다른 기구·가동범위·체중 운동의 부하를 동일한 근력 수치로 취급하지 않습니다.
- 카메라 분석은 기존 12개 동작의 참고 안내입니다. 정확도가 높아졌다는 실사 검증 주장은 없습니다.
- 전문가가 검토한 실제 시범 영상은 사용 허가·전문가 검수 자료가 필요합니다. 이번 변경은 기존 개념 시범의 안내 개선입니다.
- HealthKit / Health Connect 권한과 표본 조회는 여전히 실제 기기에서 검증해야 합니다. 클라우드 동기화·추천 연계는 하지 않습니다.

## 검증

서버: 세트 보존/중복 재시도/숫자 검증, 다른 계정 교체 거부, 안전 차단, 원본 루틴과 늦게 도착한 기록 보존.
화면: 세트 입력, 미기록 부하 처리, 준비·미래 기록 제외, 중단 세트 합계, 네이티브 표본 중복·겹침 제외.
브라우저: 기존 3D/루틴 흐름, 중량 기록의 암호화 보관 후 재접속 전송, 모바일 운동 교체→세트 입력→주간 합계.

## 운동 화면 품질 보완 (2026-10-02)

- 오늘 운동·완료 진행률·시작 버튼을 먼저 보여주고 캘린더는 펼쳐 보는 보조 영역으로 옮겼습니다.
- 운동 기록을 독립된 폼으로 구성했습니다. 중량만 수정해도 기존 메모·운동 시간·RPE·통증·난이도를 유지합니다. 네이티브 폼의 숫자 범위 검증 후 저장하며, 세트별 기록 사용 시 중복 전체 세트/반복 입력을 숨깁니다.
- 지난 세트 불러오기와 같은 세트 추가를 명시적 버튼으로 제공합니다. 저장 대기 기록은 반복 제출을 잠그고 성공/대기/오류를 구분합니다. 상세 입력은 접을 수 있고 모바일 입력 높이를 통일했습니다.
- 운동 따라하기에 일시정지를 추가했습니다. 문서가 숨겨지면 자동으로 정지하고, 계속하기 전에는 세트 완료를 막습니다. 쉬는 타이머는 남은 시간을 유지하고 운동 기록 시간에서 일시정지 기간을 뺍니다. 통증 중단 기록은 정지 중에도 가능합니다.
- 미저장 입력이 있는 상태의 목록으로 버튼은 확인을 표시하며, 브라우저 새로고침/닫기에는 beforeunload 경고를 요청합니다. OS 강제 종료 복구나 모든 앱 내부 탐색 차단을 보장하지 않으며 운동 완료 전 입력을 영구 저장하지 않습니다.
- 홈에서는 오래된 측정값을 ‘오늘’로 표시하지 않고 측정일을 표시합니다. 초기 로딩/실패/갱신이 필요한 계획을 구분하여 시작 동선을 제공합니다.
- 홈 3D 미리보기는 사용자가 열 때 모듈과 캔버스를 불러옵니다. 닫으면 캔버스를 해제하며, 최초 방문부터 3D 렌더링을 시작하지 않습니다. 실제 기기 시간·배터리 개선율은 측정하지 않았습니다.

## 날짜·진행 중 복구·시간 운동 보완

- 저장 요청에 IANA 기기 시간대를 포함하고 서버가 해당 시간대의 오늘과 루틴 생성일을 비교합니다. 기존 요청은 UTC 기본값을 유지합니다. 복구된 입력은 최초 기록 날짜·시간대를 유지해 자정이나 여행 이후 다른 날로 바뀌지 않습니다.
- 진행 중 일반 입력과 운동 따라하기 상태를 계정별 AES-GCM으로 암호화해 IndexedDB의 별도 초안 저장소에 보관합니다. 서버 확인을 거친 동일 계정으로 열어야 복구됩니다. 다른 탭의 초안 갱신은 토큰 비교로 덮어쓰지 않습니다. 로그아웃·전체 삭제 시 초안과 키를 삭제합니다.
- 기기에 임시 저장됨/저장 중/실패를 구분합니다. 상태가 저장됨으로 바뀌기 전 OS가 프로세스를 종료하면 마지막 변경은 남지 않을 수 있습니다. 앱/브라우저 저장소 삭제·OS 회수까지 복구를 보장하지 않습니다. 복구는 해당 루틴·일차 화면에서 이뤄지고 타이머는 정지 상태로 열립니다.
- 데이터 라우터의 이동 차단 기능으로 하단 메뉴, 앱 내부 링크 및 뒤로가기를 확인합니다. 동의하면 초안 저장을 기다리고 실패하면 이동을 취소합니다. 미저장 브라우저 새로고침/닫기는 beforeunload를 요청하며 운영체제가 이를 생략할 수 있습니다.
- 유지 운동은 세트별 실제 초, 유산소는 실제 수행 초를 기록합니다. 별도 타이머는 시작/정지/초기화를 제공하고 백그라운드 시간은 세지 않습니다. 일반 운동 시간(휴식 포함 경과 시간)과 실제 유지/유산소 수행시간은 별개입니다.
- 미수행/일부 수행/완료/통증 중단은 서버가 실제 본 세트 수 또는 목표 시간을 비교하여 계산합니다. 준비 세트·0회 세트는 완료 수에 포함하지 않습니다. UI 완료 플래그만으로 0세트를 완료 처리할 수 없습니다. 기존 저장 기록의 상태를 임의로 소급 변경하지는 않습니다.
- 기존 앱보다 서버를 먼저 갱신해야 시간대·시간 기록 필드가 보존됩니다. DB JSON 구조는 하위 호환이며 브라우저 저장소는 버전 2로 이동합니다. v1 클라이언트가 같은 브라우저 저장소를 동시에 사용하지 않도록 새 앱으로 갱신해야 합니다.

### 활동 집계·보관 입력·설정 보호 보완

- 수행 증거가 있는 일부 수행/통증 중단 기록도 활동 일수와 실제 시간에 포함합니다. 목표 완료 기록이 있는 날은 별도로 표시하며 미수행·통증만 있는 기록은 활동으로 세지 않습니다.
- 개인정보의 임시 입력 목록에서 이전 루틴과 날짜를 확인하고 원래 계획을 열어 복구합니다. 기존 암호화 기록도 계정 내 루틴 식별자로 찾습니다. 삭제되었거나 안전 재검토가 필요한 계획은 입력 내용 확인과 삭제만 허용합니다.
- 프로필과 안전 문진 변경 후 경로 이동·뒤로가기·새로고침 시 미저장 경고를 표시합니다. 저장 성공 시 경고를 해제하며 저장 중 필드는 잠급니다. 이 설정 입력은 자동 임시 저장하지 않습니다.
- 충돌 화면에 수행 초·세트별 유지시간·운동 시간·RPE·메모·상태를 나란히 표시합니다.
- 모바일 하단 메뉴의 멤버십 자리를 운동 기록으로 바꾸었습니다. 멤버십은 프로필의 건강 메뉴에서 접근할 수 있습니다.

### 요청 실패와 통증 중단의 기록 보존

- 프로필 저장은 두 요청의 결과를 구분합니다. 키·성별 저장이 확인된 뒤 운동 설정 요청이 실패하면 부분 저장임을 안내하고 화면 입력을 보존합니다. 같은 입력으로 재시도할 때 확인된 키·성별 요청은 반복하지 않습니다. 응답이 없으면 미저장으로 단정하지 않고 저장 확인 실패로 안내합니다. 서버 원자적 저장으로 변경한 것은 아닙니다.
- 임시 입력 목록은 계정별 로컬 암호화 기록부터 읽고 표시한 뒤 루틴을 조회합니다. 루틴 서버 오류/지연이 로컬 입력 열람을 막지 않으며 오류 후 다시 확인할 수 있습니다. 로그인 검증을 우회하지 않고, 계획이 확인되지 않으면 운동 재개 링크를 제공하지 않습니다.
- 시간 운동에서 통증 중단 시 현재 타이머 초를 유지 세트 또는 유산소 수행 시간에 포함합니다. 중단으로 표시하고 완료로 승격하지 않습니다. 기록 실패 시 입력을 유지하며 재시도에 중복 누적하지 않습니다.

### 3D 아바타 외형·변형 개선

- 기존 CC0 인체 메시를 유지하고 피부·짧은 머리·입술·눈썹/눈 주위 음영과 운동복 색상을 절차적으로 분리했습니다. 의복 부풀림을 줄이고 피부/섬유/신발의 거칠기를 구분합니다. 사진 기반 얼굴 복원이나 실사 텍스처는 아닙니다.
- 운동 변형은 정규화한 dual-quaternion blending으로 교체했습니다. 서로 반대 방향으로 굽힌 관절의 혼합 구간에서 선형 블렌딩의 단면 축소를 줄입니다. 참고 알고리즘: Kavan et al. 2008, https://users.cs.utah.edu/~ladislav/kavan08geometric/kavan08geometric.html (소스 코드를 복사하지 않은 자체 구현).
- 피부와 옷은 한 메시의 재질 그룹을 사용하여 한 번 변형하고 법선을 계산합니다. 신발은 별도의 자체 제작 운동화 메시로 표현하고 발목/발 관절을 분리해 서 있는 자세에서 발바닥 방향을 유지합니다. 바닥 보정은 모델과 손에 든 장비에 같이 적용합니다. 모바일 렌더 해상도를 제한하고 정지 시 요청 기반 렌더링을 사용합니다.
- 작은 화면에서 캔버스의 최소 너비 때문에 가로로 넘치던 레이아웃을 수정했습니다.
- 휴대폰 실측 FPS·발열, 실제 인체와의 외형 일치, 모든 자세의 접촉/충돌 해결을 검증한 것은 아닙니다. 운동 시범은 개념 안내를 유지합니다.

### 선택형 카메라 코칭

- 지원하는 12종 운동에서 위쪽 3D 시범 / 아래쪽 전면 카메라를 같은 크기로 표시합니다. 카메라 크게·시범만 보기 전환과 시범 재생/정지를 제공합니다. 운동 라이브러리 카드 및 운동 따라하기 안에서 열 수 있습니다.
- 카메라·자세 피드백·음성은 모두 기본 꺼짐입니다. 카메라만 켜면 분석 권한 요청, 모델 로딩, 추론, 관절선, 횟수나 교정 안내를 실행하지 않습니다. 사용자가 `자세 피드백 받기`를 켠 경우에만 기존 구독 권한을 검증한 뒤 기기 내 분석을 시작합니다. 음성은 별도 선택입니다.
- 피드백 해제 시 모델과 예약 프레임을 해제하고 화면 결과·관절선·음성을 즉시 지웁니다. 늦게 도착하는 권한/모델/추론 결과는 세대 번호로 폐기합니다. 카메라는 거울로 유지됩니다. 분석 오류도 카메라를 강제로 끄지 않습니다.
- 카메라 끄기·화면 숨김·닫기·운동 변경·운동 일시정지/휴식/통증 입력 시 카메라 트랙과 분석을 종료합니다. 재시작 시 피드백을 다시 선택해야 합니다. 선택 상태는 저장하지 않습니다.
- 카메라와 관절선을 같은 비율로 표시하고 같이 좌우 반전합니다. 추적이 불확실하면 자세 판정을 보류하며 한 번에 한 안내만 표시합니다. 마이크를 요청하지 않고 영상 녹화·저장·업로드는 하지 않습니다. 횟수는 참고 표시이며 운동 기록에 자동 저장하지 않습니다.
- 단위 테스트는 선택·해제·비동기 경합·분석 실패·종료를 모의 분석기로 검증합니다. 브라우저 테스트는 가상 카메라로 모바일 분할 비율·권한 실패·운동 변경 시 트랙 종료를 확인합니다. 실제 사람 영상의 판정 정확도와 물리 휴대폰 성능 검증은 별도입니다.

### 카메라 코칭 안정성 보완

- 화면 밖 판정은 원본 정규화 좌표로 수행하고 이후 영상 높이/너비 비율을 각도 계산에만 적용합니다. 세로 영상의 발목이 잘못 화면 밖으로 처리되던 문제를 수정했습니다.
- 한 앱 창에서 카메라 소유자를 한 명으로 제한합니다. 새 운동에서 카메라를 시작하면 기존 스트림·분석과 대기 중 권한 요청을 무효화하며, 늦게 승인된 이전 스트림은 즉시 종료합니다. 별도 브라우저 탭 사이의 장치 독점은 보장하지 않습니다.
- 피드백 준비에 20초 제한을 적용하고 권한/모델 HEAD 요청을 취소합니다. 초기화 중 worker를 종료하고 뒤늦게 생성된 분석기는 폐기합니다.
- 새 분석 결과가 3초 동안 없으면 이전 결과·관절선·음성을 제거하고 피드백을 종료합니다. 카메라는 유지하고 다시 켜도록 안내합니다. JavaScript 메인 스레드 자체가 완전히 멈춘 동안에는 타이머도 실행되지 못합니다.
