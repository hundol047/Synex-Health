Use the live App Store Connect questionnaire; do not guarantee an age rating. Apple's updated definitions: https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions/ .

| Topic | Source-based answer to review |
|---|---|
| Violence, weapons, horror, gambling, simulated gambling, contests | None implemented |
| Sexual content / nudity | No sexual content. Body surface uses a visualization suit; exercise avatars wear sportswear. Review every angle before submitting “None.” |
| Alcohol/tobacco/drugs, profanity | None authored |
| Medical/treatment information | General fitness/body-composition guidance; no diagnosis/treatment. Assess Apple's health/wellness definitions in the live questionnaire instead of calling this a medical device. |
| User-generated content | Private user-entered notes and counselor notes; no public feed. Disclose according to the questionnaire's exact definition. |
| Messaging/chat | Private rule-based assistant and counselor notes, no public person-to-person chat; disclose interactive assistant accurately. |
| Unrestricted web access | No embedded unrestricted browser; external login, legal and store-management URLs only |
| Advertising/tracking | None |
| In-app purchases | Yes only for Plus launch; auto-renewable subscriptions |
| Parental controls / age assurance | Not implemented; do not claim child-directed design or Kids Category |

Physical-device accessibility and content review remain required. Operator must choose supported ages and finalize policy. Do not infer that a 4+ result makes exercise recommendations suitable for children.
