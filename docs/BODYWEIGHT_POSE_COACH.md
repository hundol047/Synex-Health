# 맨몸운동 카메라 코치

개인용 Android 앱의 홈에서 `맨몸운동 카메라 코치`를 엽니다. 위쪽에는 3D 운동 시범과 현재 단계의 설명을, 아래쪽에는 내 카메라 영상과 관절선을 같은 크기로 표시합니다. 화면 상단에서 스쿼트, 런지, 사이드 런지, 푸시업, 플랭크, 힙힌지, 글루트 브리지를 선택합니다.

`코칭 시작`은 카메라 권한을 요청한 뒤 기기에 포함된 MediaPipe Pose Landmarker Lite 모델로 분석을 시작합니다. `카메라 켜기`는 영상만 표시합니다. 자세 피드백과 한국어 음성 안내는 각각 끌 수 있으며 전면/후면 카메라를 전환할 수 있습니다. 다른 운동을 선택하거나 화면을 나가면 카메라와 분석을 종료합니다.

한 명의 전신과 바닥 지지점이 화면 안에 보이도록 휴대폰을 고정하세요. 촬영 방향은 각 운동 화면에 표시합니다. 추적 상태를 확인한 뒤 무릎 방향, 몸통 기울기, 골반과 몸통 정렬, 팔 지지점, 보폭 등을 관찰합니다. 교정할 부위를 관절선과 점에 붉게 표시하고 동작을 조정하는 문구를 보여줍니다. 가려진 관절, 화면 밖 신체, 여러 사람, 불확실한 촬영 방향에서는 해당 판정을 보류합니다. 통증이 있으면 운동을 중지하세요.

영상 파일을 녹화하거나 저장하지 않습니다. 서버 로그인, 분석 API, 외부 모델 다운로드가 필요하지 않으며 추정 횟수는 운동 기록에 자동 저장하지 않습니다. 개인용 빌드의 외부 통신을 Content Security Policy로 차단하고, 분석 작업의 fetch/XMLHttpRequest/sendBeacon도 기기 자산의 출처로 제한합니다.

## 개발과 빌드

```bash
cd frontend
npm ci
npm run pose:setup
VITE_LOCAL_ONLY=true npm run dev
npm test -- --maxWorkers=3
npx playwright test --config playwright.local.config.js
npm run android:local
```

개인용 APK 빌드는 공식 모델의 고정 SHA-256을 확인하고 모델과 WASM을 함께 포함합니다. 설치된 모델의 체크섬이 다르면 빌드를 중단합니다. Android 빌드에는 JDK 21과 Android SDK 36이 필요합니다. 기존 수정판 업데이트는 동일한 `com.synex.health.personal.storagefix` 앱 ID와 서명 키를 유지하고 버전 코드를 올려야 합니다.

## 검증 범위

자동 테스트는 모바일 위아래 배치, 운동 선택, 카메라 권한 거부와 재시도, 카메라 전환 및 종료, 관절 추적의 불확실성 처리, 부위별 교정 규칙과 3D 관절의 운동 동작을 확인합니다. 실제 공식 사람 사진을 입력한 별도 확인은 모델이 33개 관절을 추출하고 기기 자산만으로 추론을 수행하는지 확인합니다.

이 확인은 실제 운동 영상에서의 교정 정확도 검증을 대체하지 않습니다. 여러 휴대폰과 체형의 실제 운동 영상으로 독립 평가해야 하며, 클라우드에서 사용자 휴대폰의 카메라와 실행 성능을 직접 검증하지 않았습니다. 3D 시범은 작성된 운동 동작이며 전문가의 모션 캡처 데이터는 아닙니다.
