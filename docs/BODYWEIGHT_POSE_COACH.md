# 맨몸운동 카메라 코치

개인용 Android 앱의 홈에서 `맨몸운동 카메라 코치`를 엽니다. 위쪽에는 3D 운동 시범과 현재 단계의 설명을, 아래쪽에는 내 카메라 영상을 같은 크기로 표시합니다. 맨몸운동 42종을 선택해 촬영할 수 있으며, 실시간 관절 추적과 교정은 스쿼트, 런지, 사이드 런지, 푸시업, 플랭크, 힙힌지, 글루트 브리지 7종에서 제공합니다. 나머지 운동은 촬영만 지원한다고 표시합니다.

`코칭 시작`은 카메라 권한을 요청한 뒤 기기에 포함된 MediaPipe Pose Landmarker Lite 모델로 분석을 시작합니다. `카메라 켜기`는 영상만 표시합니다. 자세 피드백과 한국어 음성 안내는 각각 끌 수 있으며 전면/후면 카메라를 전환할 수 있습니다. 다른 운동을 선택하거나 화면을 나가면 카메라와 분석을 종료합니다.

한 명의 전신과 바닥 지지점이 화면 안에 보이도록 휴대폰을 고정하세요. 촬영 방향은 각 운동 화면에 표시합니다. 추적 상태를 확인한 뒤 무릎 방향, 몸통 기울기, 골반과 몸통 정렬, 팔 지지점, 보폭 등을 관찰합니다. 교정할 부위를 관절선과 점에 붉게 표시하고 동작을 조정하는 문구를 보여줍니다. 가려진 관절, 화면 밖 신체, 여러 사람, 불확실한 촬영 방향에서는 해당 판정을 보류합니다. 통증이 있으면 운동을 중지하세요.

`동영상 촬영`을 누를 때만 카메라 원본을 최대 60초 녹화합니다. 종료하면 아래 화면에서 다시 재생할 수 있고, `휴대폰에 저장` 또는 `공유`를 직접 눌러 내보냅니다. 마이크를 요청하지 않으며 관절선과 음성 안내는 촬영 파일에 포함하지 않습니다. 저장 전 영상은 메모리에만 있고, 백그라운드 전환·화면 종료·운동 변경 시 카메라 트랙과 분석을 종료하고 진행 중 촬영과 내보내지 않은 영상을 폐기합니다.

Android 10 이상 저장 위치는 `다운로드/Synex Health`이며, 이전 Android에서는 시스템 공유 창을 사용합니다. 내보낸 동영상과 공유용 임시 파일은 앱의 AES-GCM 건강 기록 저장소와 별개의 암호화하지 않은 영상 파일입니다. 저장한 파일은 앱을 나가도 남습니다. 앱은 영상을 자동 업로드하지 않으며 공유받는 앱의 저장·전송은 사용자가 선택한 앱이 처리합니다. Android 실기기의 저장·공유 동작은 아직 직접 검증하지 않았습니다.

서버 로그인, 분석 API, 외부 모델 다운로드가 필요하지 않으며 추정 횟수는 운동 기록에 자동 저장하지 않습니다. 개인용 빌드의 외부 통신을 Content Security Policy로 차단하고, 분석 작업의 fetch/XMLHttpRequest/sendBeacon도 기기 자산의 출처로 제한합니다.

## 동작과 모바일 화면 개선

시범은 준비·천천히 움직이기·자세 확인·돌아오기 구간을 부드럽게 이어갑니다. 런지는 앞발을 고정하고 뒷발을 들어 이동한 뒤 내려가며, 바닥 운동은 발끝과 손·팔뚝 지지를 유지합니다. 시점 선택에서 정면·45도·측면을 고정해 보여주고, 일반 운동 상세 화면의 `자유` 시점에서 회전할 수 있습니다. 일반 상세 시범은 초당 30회 갱신을 목표로 하며 실제 속도는 기기에 따라 달라집니다. 좌우 교대 런지는 더 천천히 재생합니다.

휴대폰 세로 화면은 위 시범과 아래 카메라를 같은 크기로 유지합니다. 피드백을 카메라 아래의 별도 줄에 두어 손과 발을 가리지 않습니다. 짧은 가로 화면에서는 두 화면을 나란히 배치하며, 아주 짧은 세로 화면이나 길어진 오류 안내는 스크롤해 읽을 수 있습니다. 홈에는 카메라 코치와 마네킹 바로가기를 두고, 저장된 측정값과 운동 계획에 따라 다음 단계를 표시합니다. 주요 코칭 조작 버튼은 44px 이상의 터치 영역을 사용합니다.

## 개발과 빌드

### 자동 템포·음성·관찰 요약 (1.9)

운동 기록 화면의 `자동 시범 · 휴식 맞춰 따라하기`는 루틴 순서대로 5초 준비,
각 세트의 시범, 회복, 다음 운동을 자동 진행합니다. 카메라 화면에서도 선택한
운동을 같은 타이머에 맞춰 따라할 수 있습니다. 시범 위치와 반복 카운트가 하나의
시계를 사용하며 좌우 교대는 한쪽 수행을 1회로 셉니다. `각 8회` 처방은 양쪽
합계 16회입니다. 시간 운동은 처방 초를 사용합니다. 루틴 휴식을 우선 반영하고
없으면 가동성 20초, 유지 45초, 일반 60초, 큰 근육·편측 동작 90초를 제안합니다.
휴식은 10–120초로 조절하며 마지막 운동 뒤에도 포함합니다. 화면 숨김, 일시정지,
1.5초 넘는 표시 지연은 자동 진행을 멈춥니다. 타이머 완료를 실제 수행으로
저장하지 않으며 `실제 수행 기록하기`에서 수행량과 통증을 확인합니다.

`운동 음성 · 이름·초·횟수 읽기`를 켜면 이름과 준비 카운트, 시범 횟수 또는
운동 경과 초, 휴식 남은 초를 한국어로 읽습니다. 카운트와 교정 음성은 겹치지
않습니다. Android는 등록된 `WorkoutSpeechPlugin`과 설치된 오프라인 한국어 TTS
음성을 사용합니다. 음성이 없으면 설정 안내를 표시하며 자동 다운로드하지
않습니다. 웹은 Web Speech API를 사용합니다. 음성은 화면을 벗어나면 종료합니다.

`촬영·분석 함께 시작`은 실제 촬영 중 MediaPipe 관절 결과를 관찰 요약에
집계합니다. 보이는 각도, 정렬 차이와 교정 방법, 운동별 힘 사용 안내를 분리해
표시합니다. 관절 각도는 화면 비율을 보정한 2D 각도이며 추정 z를 섞지 않습니다.
300ms 미만의 순간적 교정 후보는 강조하지 않습니다. 정렬을 판정할 수 없는
방향·가림·추적 끊김은 보류하며, 준비·휴식·일시정지 구간은 세지 않습니다.
촬영 후 관찰 시간, 완전한 반복, 지속된 교정 항목을 표시합니다. 분석 가능한
프레임/시간이 부족하면 결론을 보류합니다. 힘 사용법은 운동 설명이며 영상으로
측정한 근육 활성도가 아닙니다. 스캔·임상 진단이나 42종 전체 교정으로 표시하지
않습니다. 실시간 교정은 위에 명시한 7종입니다.

새 검증은 현재 소스에서 생성한 Vitest/Playwright 보고서만 사용합니다. 이전
1.8 배포 보고서는 1.7 브라우저 결과가 재사용되어 1.8의 신규 실행 증거로 쓸 수
없습니다. 이전 결과를 새 버전의 통과 수에 합산하지 않습니다.

```bash
cd frontend
npm ci
npm run pose:setup
VITE_LOCAL_ONLY=true npm run dev
npm test -- --maxWorkers=3
npx playwright test --config playwright.local.config.js
npm run android:local
```

개인용 APK 빌드는 공식 모델의 고정 SHA-256을 확인하고 모델과 WASM을 함께 포함합니다. 설치된 모델의 체크섬이 다르면 빌드를 중단합니다. Android 빌드에는 JDK 21과 Android SDK 36이 필요합니다. 기존 수정판 업데이트는 동일한 `com.synex.health.personal.storagefix` 앱 ID와 서명 키를 유지하고 버전 코드를 올려야 합니다.

## 검증 범위

자동 테스트는 모바일 위아래 배치, 운동 선택, 카메라 권한 거부와 재시도, 카메라 전환 및 종료, 관절 추적의 불확실성 처리, 부위별 교정 규칙과 3D 관절의 운동 동작을 확인합니다. 실제 공식 사람 사진을 입력한 별도 확인은 모델이 33개 관절을 추출하고 기기 자산만으로 추론을 수행하는지 확인합니다.

이 확인은 실제 운동 영상에서의 교정 정확도 검증을 대체하지 않습니다. 여러 휴대폰과 체형의 실제 운동 영상으로 독립 평가해야 하며, 클라우드에서 사용자 휴대폰의 카메라와 실행 성능을 직접 검증하지 않았습니다. 3D 시범은 작성된 운동 동작이며 전문가의 모션 캡처 데이터는 아닙니다.
