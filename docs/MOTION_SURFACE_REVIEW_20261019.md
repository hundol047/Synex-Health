# 운동 표면·손목 회귀 수정

## 수정 원인과 결과

- **벽 푸시업 손목**: 월드 X 좌표로 손/팔의 가중치를 나누면서 같은 손목 단면의 양쪽이 서로 다르게 회전했습니다. 손목의 해부학적 축을 따라 가중치를 보간하도록 변경해 단면이 찌그러지는 현상을 제거했습니다. 모든 운동·스트레칭의 공통 표면에 적용됩니다.
- **벽을 짚는 손바닥**: 바닥 손바닥을 대략 회전하던 방식을 실제 손의 방향·손등 프레임으로 대체했습니다. 손가락은 위, 손바닥은 벽을 향하고 아래팔의 회전도 이어집니다. 벽 푸시업·좁은 벽 푸시업·벽을 짚는 종아리 스트레칭에 적용됩니다.
- **이마와 벽 간격**: 손목 수정 뒤 더 정확해진 벽 접촉면에서 작은 체형의 이마가 지나치게 가까워지는 것을 확인했습니다. 벽 푸시업의 최종 기울기를 줄이고, 전체 표면 및 신발의 벽 관통과 이마 여유 간격 검사를 유지했습니다.
- **누워 발뒤꿈치 터치의 엉덩이**: 들린 허벅지가 원래 방향과 거의 반대가 되면서 월드 공간의 최단 회전이 옆으로 반 바퀴 도는 해를 선택했습니다. 엉덩이 표면이 허벅지 안쪽으로 뒤집혀 측면에서 사라져 보였습니다. 누운 몸통 프레임에서 팔다리 회전을 계산하도록 바꾸었습니다. 발뒤꿈치 밀기도 같은 기준으로 정렬했습니다.
- 운동 라이브러리 대표 이미지 74장을 실제 수정된 WebGL 렌더러에서 다시 생성했습니다.

## 확인 방식

- 74개 운동 + 30개 회복 스트레칭의 전체 표면을 0·25·50·75% 구간으로 렌더링하여 검토했습니다. 관절 좌표가 유효한지만 확인하지 않고 피부·옷의 변형을 함께 봤습니다.
- 104개 모션의 손목·발목 방향 및 전환 연속성을 240개 구간에서 검사합니다. 손의 별도 회전(`handRoll`)도 검사에 포함합니다.
- 벽 지지 모션은 남성·여성·중간 체형과 여러 크기에서 피부·옷·머리·발 및 실제 신발의 접촉 위치를 검사합니다.
- 손목 단면이 벽을 짚는 동작 중에도 둥글게 유지되는 회귀 테스트와, 누운 발뒤꿈치 터치의 양쪽 엉덩이 표면이 뒤집히지 않는 회귀 테스트를 추가했습니다.
- 벽 푸시업·좁은 벽 푸시업·발뒤꿈치 터치·발뒤꿈치 밀기를 실제 브라우저의 확대/측면/45도 화면으로 별도 확인했습니다.

재실행: `cd frontend && npx vitest run tests/HandDetail.test.js tests/WallSupportSurface.test.js tests/FloorCatalogRig.test.js tests/StandingCatalogRig.test.js tests/AllMotionContinuity.test.js tests/EquipmentCatalogRig.test.js`.

물리적 Android 휴대폰에서의 확인이나 실제 사람 운동 영상의 교정 정확도 검증은 포함되지 않습니다. 기하학적 회귀 검사와 렌더링 검토는 모든 체형·각도·프레임에서 결함이 없음을 보증하지 않습니다.
