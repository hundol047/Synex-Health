각 대본의 질의응답 뒤 맨 마지막에 정리했습니다.

## 실적과 계획의 구분

현재 소스에 구현된 콘텐츠·기능 범위만 구현 사항으로 적었습니다. 운동 74종과
스트레칭 30종은 콘텐츠 수이며, 모든 동작의 실제 분석 정확도 입증 수치가 아닙니다.
자동 검사 결과를 임상 효과·정확도로 표현하지 않습니다.

학생 15명·담당자 3명 인터뷰, 참여자 20명·전문가 2명·운동 5종 평가, 기관 1곳의
4주 실증, 첫 운동 완료율 70%와 4주 재사용률 30%, 5분용의 기관당 월 10만~30만 원,
검증 예산 500만 원은 모두 **검증 계획·가격 가설·제안 예산**입니다.
계약, 협약, 매출, 조달 또는 고객 성과가 확정된 수치로 사용하지 않습니다.
500만 원은 초기 검증 예산으로, 창업자 인건비와 전체 상용 운영비는 별도입니다.

경쟁 서비스 설명은 Nike 공식 사이트와 Hevy/Fitbod의 공식 App Store 소개를
2026-11-01 확인한 내용입니다. 서비스마다 소개하는 초점을 비교하며,
다른 앱에 특정 기능이 없다고 단정하지 않습니다.

## 7분용 전국 기관 시장·구독료 확대

7분용은 기관용(B2B)과 개인용(B2C)을 원으로 구분했습니다. 총 11장·420초이며
5분용 PPT·대본·PDF는 기존 대학 중심 버전을 유지했습니다. 원 면적은 시장 규모에 비례하지 않습니다.

- 기관 범위: 전국 신고 헬스장 + 대학 스포츠센터 후보군입니다.
- 헬스장: 문체부 「2025 전국 등록·신고 체육시설업 현황」의 2024년 말 체력단련장업 15,548개소입니다.
  국민체육진흥공단 공개 PDF 12·13쪽에서 확인했습니다.
- 대학: 2026년 고등교육기관 416개교에서 원격·방송·사이버 23개교와 독립 대학원 등 45개교를 제외해
  캠퍼스형 학부기관 후보 348개교를 산정했습니다. **학교당 센터 1곳은 가정**이며 실제 센터 수가 아닙니다.
- 기관 요금 가설: **헬스장 월 49만 원 / 대학 스포츠센터 월 99만 원**입니다.
  사용량·계정 수·운영 지원·구축 및 연동비와 지불 의향을 검증해야 합니다.
- 기관 TAM: 15,548곳 × 49만 원 × 12 + 348곳 × 99만 원 × 12 = **95,556,480,000원(약 955.56억 원)**입니다.
- 기관 SAM: 유형별 10%를 버림한 헬스장 1,554곳 + 대학 34곳 = **9,541,440,000원(약 95.41억 원)**입니다.
- 기관 SOM: 출시 후 24개월에 헬스장 30곳 + 대학 5곳 = **235,800,000원(약 2.36억 원)**을 목표로 제안했습니다.
- 위 금액은 **12개월 유지 시 연환산 잠재 이용료**입니다. 첫해·24개월 누적 매출 또는 확정 계약이 아닙니다.
  학교당 센터 1곳과 시설 중복 없음의 가정에 따른 상한입니다. 실제 사업장·운영주체별로 중복을 제거해야 합니다.
- 개인용은 초기 일반·전문대학 재적학생 2,372,654명과 월 4,900원의 기존 가설을 유지했습니다.
  재적학생에는 휴학생 등이 포함되며 기관용과 개인용의 시장 금액을 단순 합산하지 않습니다.
- SAM 10%, 기관 35곳·개인 유료 회원 500명의 24개월 SOM은 조사 실적이 아닌 가정·목표입니다.
- 산식·통계 단위·가격의 제안 범위·중복 처리와 출처는 **7분 대본 맨 뒤 근거와 자료**에 있습니다.
  `market.py`, `market-model.json`, `market-source-records.json`에 정확한 값과 원문 해시를 저장했습니다.

## 수정·재생성

`content.py`에서 장별 문구·대본·질의응답을, `build.py`에서 레이아웃을 수정합니다.
`python-pptx`, `python-docx`, Pillow가 필요합니다.

```sh
python docs/pitch-0713/build.py
# 7분용만 갱신하려면 다음을 실행합니다.
python docs/pitch-0713/build.py --minutes 7
```

PDF는 LibreOffice로 변환하고, 이미지 배치·문장 넘침·폰트 렌더링을 확인합니다.
