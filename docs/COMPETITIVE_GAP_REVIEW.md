# 경쟁 앱 대비 차별성·부족 기능 점검 (2026-11-21)

비교 대상 유형: 체성분 측정 앱(InBody 앱), 종합 헬스 앱(Samsung Health·Apple 건강), 근력 운동 기록·추천 앱(Fitbod·Hevy·Strong).
아래 기능 존재 여부는 이 저장소 소스 기준이며, 경쟁 앱 기능은 일반적인 공개 기능 범주로 비교했습니다.

## Synex Health의 차별점 (유지)

| 영역 | Synex Health | 일반 경쟁 앱 |
|---|---|---|
| 측정 → 운동 연결 | 부위별 체성분(팔·몸통·다리) 기반 루틴 생성, 재측정 시 루틴 자동 재검토 | 체성분 앱은 측정 표시 위주, 운동 앱은 체성분 미사용 |
| 시각화 | 측정값 기반 3D 인체 morph, 비교군 평균 오버레이, Before/After | 2D 그래프 위주 |
| 학교 건강센터 | 학교 선택, 동의 기반 상담사 조회, 상담 메모 | 기관 연동 없음 |
| 운동 시범 | 74종 자체 3D 시범, 카메라 자세 피드백(실험적), 템포·음성 안내 | 영상/GIF 위주 |
| 안전 | 통증 기록 시 자동 증량 차단, 문진 차단, 미검증 수치 명시 | 대체로 없음 |
| 개인 모드 | 서버 없이 로컬 암호화 저장·암호 백업 | 계정·클라우드 필수 |

## 부족했던 부분과 이번 수정

| 부족 기능 | 경쟁 앱 현황 | 조치 |
|---|---|---|
| 개인 최고 기록(PR) | Hevy·Strong·Fitbod 기본 제공 | **추가** — `/health/progress` "개인 최고 기록": 운동별 최고 중량, 맨몸 최고 횟수, 최근 갱신 표시. 준비 세트·통증 기록 세트·미래 날짜 제외 |
| 추정 1RM | Strong·Fitbod 제공 | **추가** — Epley 공식, 10회 이하 중량 세트만 계산, 참고값임을 명시 |
| 부위별 훈련량 | Fitbod 근육 회복/볼륨 표시 | **추가** — 상체·몸통·하체별 이번 주 본 세트와 이전 4주 주평균 |
| 측정 결과 ↔ 실제 훈련 연결 | 경쟁 앱에 없음 (차별 기능 강화) | **추가** — "측정 결과 ↔ 실제 훈련량": 최근 측정에서 기준 대비 90% 미만 부위의 훈련 비중이 30% 미만이면 루틴 확인 안내. 진단·처방이 아님을 명시 |

구현: `frontend/src/health/lib/trainingInsights.js`, `frontend/src/health/components/TrainingProgress.jsx`,
테스트 `frontend/tests/TrainingInsights.test.jsx`. 서버 모드와 개인(로컬) 모드 모두 동작합니다(로컬 기록은 운동 이름으로 카탈로그 부위를 찾습니다).

## 2차 개선: 조작 단순화 (2026-11-21)

| 문제 | 수정 |
|---|---|
| 새 사용자가 루틴 화면에서 "내 운동 계획 만들기"를 누르면 "문제가 발생했습니다 · 체성분 측정값을 먼저 입력하세요"와 성공할 수 없는 "다시 시도" 버튼만 표시됨 | 개인(로컬) 모드: 측정값 없이도 낮은 부담의 **시작 계획**을 즉시 생성하고, 체성분 입력 버튼을 함께 표시. 서버 모드: 오류 대신 "체성분을 먼저 입력해 주세요" 안내와 측정 입력 폼으로 바로 이동하는 버튼 |
| 프로필 화면이 휴대폰에서 약 4,300px로 길어 원하는 항목을 찾기 어려움 | 상단에 `체성분 입력 · 내 정보 · 운동 목표 · 안전 문진` 바로가기 버튼 추가 |
| 변화 추적 화면의 5열 표가 휴대폰에서 가로로 넘침, 기록이 없어도 0으로 채운 8주 표 표시 | 맨 위에 "이번 주" 요약 타일 4개(운동한 날·본 세트·중량×횟수·최근 갱신 기록, 지난주 대비). 상세 표와 주의 문구는 "자세히 보기"로 접음. 기록이 없으면 한 줄 안내만 표시 |
| 개인 최고 기록·측정↔훈련 연결이 넓은 표 | 휴대폰용 카드 목록과 훈련 비중 막대, 상태 배지(유지·진행 중·훈련 비중 확인)로 변경 |

## 아직 남은 격차 (이번에 구현하지 않음)

- **수분·수면·단백질 간단 체크**: 건강 기록은 기기 암호화 저장소에만 두는 원칙이 있어, 저장 구조(문서 버전) 변경과 백업 호환 검토 후 추가해야 합니다.
- **식단·단백질 기록**: 경쟁 종합 헬스 앱은 제공. 체성분 목표와 연결하면 차별성이 크지만, 영양 권고는 전문가 검토가 필요해 보류했습니다.
- **수면·심박 등 웨어러블 지표**: HealthKit/Health Connect 연결 구조는 있으나, 화면에서 수면 데이터를 활용하지 않습니다.
- **다크 모드**: 전용 테마가 없습니다. CSS에 직접 쓴 색상이 613곳이라 한 번에 바꾸면 화면이 깨질 위험이 커서, 색상 토큰 정리 후 진행하는 것이 안전합니다.
- **소셜·챌린지**: 친구·학교 단위 챌린지 기능이 없습니다(학교 연동과 결합할 수 있음).
- **홈 화면 위젯·워치 앱**: 없음.
- 기존 문서의 외부 검증 항목(실기기, 실제 사람 자세 정확도, 스토어 결제, 학교 API)은 여전히 미완료입니다. [PERSONAL_RELEASE_READINESS.md](PERSONAL_RELEASE_READINESS.md) 참고.
