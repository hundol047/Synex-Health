# 국내 대학 센터 조사 및 실제 데이터 연동 요건

확인일: 2026-10-19 (한국시간). 공개 공식 페이지를 직접 조회했다. 기관에 연락하거나 계정을 생성하지 않았으며, 아래 대학은 Synex Health의 제휴 기관이 아니다. 전국 모든 대학의 센터를 조사한 결과도 아니다.

## 찾은 실제 인바디 연결 경로

- [InBody Connect 공식 안내](https://inbody.com/kr/ko/products/category/software/23): Web API/Partner API와 별도 직접 연동 방식을 안내한다. 전문가용 장비의 Web API는 서버 간 연동이다. LookinBody120은 측정 완료 시 지정 폴더에 CSV·결과지 이미지를 만들며, 이를 가져오는 기능은 별도 구현 대상이라고 명시한다.
- [한국 LookinBody Web API 가이드](https://apikr.lookinbody.com/Home/Document): 기관 LookinBodyWeb 계정으로 접근키를 발급받는다. 인증은 `Account`와 `API-KEY` 헤더이며, 공개 연결 검사 예시는 `POST /user/test`이다. `UserID`는 해당 계정의 로컬 범위, `UserToken`은 연결된 로케이션 범위라는 차이가 있다. 전화번호만 입력해 임의로 타인의 데이터를 조회하는 경로를 만들지 않는다.
- [접근키 발급](https://apikr.lookinbody.com/Home/KeyNew)과 [상세 API 문서](https://apikr.lookinbody.com/APIPage)는 직접 조회했으나 로그인 필요 화면이었다. 측정값 엔드포인트와 응답 필드 계약을 확인하지 못했으므로 이를 추측하여 구현하지 않았다.

2026-10-19 이 작업 환경에는 학교 OIDC 설정, LookinBody 계정·API 키, 기관 연동 계약이 구성되어 있지 않았다. 따라서 인증된 실 API 호출이나 실제 학생 기록 가져오기는 실행하지 않았다. 공식 홈페이지를 열었다는 사실은 데이터 연결 성공의 근거가 아니다.

## 실제 자동 가져오기를 완료하려면

1. 검사 안내가 확인된 대학 중 참여 기관을 확보하고, 해당 센터의 장비·LookinBody 운영 방식과 허용되는 데이터 제공 범위를 확인한다. 첫 기술 검토 후보는 서울대·포스코 스포츠센터, 고려대 건강센터, 강원대 춘천 보건진료소다. 이용자 소속이나 제휴 상태는 임의 지정하지 않는다.
2. 인바디의 공식 데이터 연동 절차에 따라 해당 기관용 계정·접근키, 승인된 상세 API 문서와 샘플을 확보한다. 기관별 데이터 범위 및 부위별 값의 정의·단위·검사 ID를 확인한다.
3. 키는 서버 비밀 저장소에만 설정한다. 채팅·Git·APK에 키를 넣지 않는다. 현재 기기 전용 APK에는 서버나 기관 인증을 설정하지 않았다.
4. 승인된 계약에 맞는 서버용 어댑터를 구현한다. 기존 `providers/inbody.py`의 일반 계약 주입 예시는 GET/Bearer 방식이므로 한국 LookinBody 공식 POST/Account/API-KEY 방식과 그대로 호환되지 않는다. API 주소만 바꿔서 배포하면 안 된다.
5. 학생 본인 인증, 측정 계정 확인, 가져오기 동의, 기관별 접근 범위 및 철회 흐름을 연결한다. 학교 상담사에게 공유하는 동의와 본인 측정값 가져오기 동의를 혼동하지 않는다.
6. 실제 승인 계정으로 연결·샘플 조회·중복 방지·오류 복구·학교 변경 시 접근 차단을 검증한 뒤에만 자동 연동 완료로 표시한다.

## 기관에 전달할 문의 초안 (미발송)

> Synex Health에서 이용자 본인의 체성분 측정 기록을 동의 기반으로 가져오는 연동을 검토하고 있습니다. 귀 센터의 체성분 장비 및 LookinBody/인바디 클라우드 사용 여부, 외부 서비스 연동 가능 여부와 담당 부서를 안내 부탁드립니다. 가능한 경우 공식 API 신청 절차, 기관별 접근 범위, 학생 본인 인증·동의 요건, 전신 골격근량 및 부위별 제지방/근육 분석 값의 제공 범위와 단위를 확인하고 싶습니다. 공개 안내만으로 제휴나 데이터 접근 권한이 있다고 표시하지 않으며, 실제 개인정보 제공 이전에 승인과 계약·기술 검증을 진행하겠습니다.
